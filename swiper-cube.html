配置说明

  • ①无缝循环：loop: true，最后一张往后翻会回到第一张。
  • ②3.2 秒自动翻页且手动操作后不停止：autoplay.delay: 3200 + disableOnInteraction: false。
  • ③圆点分页器可点击：pagination.el: '#wyjcxPag4' + clickable: true。
  • ④初始效果为 cube：effect: 'cube'，配合 cubeEffect 调整立体阴影。
const jcx_sw4 = new Swiper('#wyjcxSw4', {
  loop: true,              // ① 无缝循环
  effect: 'cube',          // ④ 初始效果 cube
  speed: 700,
  cubeEffect: {
    shadow: true,
    slideShadows: true,
    shadowOffset: 20,
    shadowScale: 0.94
  },
  autoplay: {
    delay: 3200,           // ② 每 3.2 秒翻页
    disableOnInteraction: false // ② 手动操作后不停止
  },
  pagination: {
    el: '#wyjcxPag4',    // ③ 圆点挂载元素
    clickable: true       // ③ 圆点可点击
  }
});

演示二四项配置原样保留，只把 effect 换成 'creative'，再补一段 creativeEffect 描述前后两张的站位：

creativeEffect: {
  limitProgress: 2,
  prev: {                        // 上一张：缩小左移并带角度退场
    shadow: true,
    translate: ['-120%', 0, -300],
    rotate: [0, 0, -10],
    scale: 0.7,
    opacity: 0.6
  },
  next: {                        // 下一张：放大从右侧进场
    shadow: true,
    translate: ['120%', 0, 0],
    rotate: [0, 0, 10],
    scale: 1.15
  }
}

演示三用的是 Swiper 的 zoom 模块：slide 里先包一层 .swiper-zoom-container，双击图片放大，再次双击还原；放大状态下可拖动查看细节，此时翻页不会误触发。

zoom: {
  maxRatio: 3,       // 最多放大到 3 倍
  minRatio: 1,
  toggle: true     // 双击切换放大 / 还原
}
