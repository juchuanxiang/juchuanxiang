1提示词工程师（迭代 2 轮）

目标：不写代码，只用提示词让 AI 生成 new Swiper('#wySw4', {...}) 配置——① 无缝循环 ② 3.2 秒自动翻页且手动操作后不停止 ③ 圆点可点击 ④ 初始效果 cube。

第 1 轮提示词（故意留缺口）

帮我写一个 Swiper 11 的初始化配置，挂载在 #wySw4 上，变量名 jcx_sw4。要求：① 无缝循环；② 每 3.2 秒自动翻页；③ 底部圆点分页器可以点击跳转，分页器元素是 #wyPag4；④ 初始效果为 cube 立方体效果。

第 1 轮 AI 回答

const jcx_sw4 = new Swiper('#wySw4', {
  loop: true,                 // ① 无缝循环
  effect: 'cube',             // ④ 初始效果 cube
  autoplay: { delay: 3200 },  // ② 每 3.2 秒自动翻页
  pagination: {
    el: '#wyPag4',            // ③ 圆点挂载元素
    clickable: true           // ③ 圆点可点击
  }
});
❌ 验证不通过：轮播能循环、能自动翻页、圆点能点，但用手拖动一次之后自动播放就停了。一句话结论：提示词漏掉"手动操作后不停止"这个约束，AI 就按默认值 disableOnInteraction: true 生成了。

第 2 轮提示词（补全约束）

帮我写一个 Swiper 11 的初始化配置，挂载在 #wySw4 上，变量名 jcx_sw4。要求：① 无缝循环；② 每 3.2 秒自动翻页，并且用户手动拖动或点击之后，自动播放不能停，要继续；③ 底部圆点分页器可以点击跳转，分页器元素是 #wyPag4；④ 初始效果为 cube 立方体效果。

第 2 轮 AI 回答

const jcx_sw4 = new Swiper('#wySw4', {
  loop: true,                 // ① 无缝循环
  effect: 'cube',             // ④ 初始效果 cube
  speed: 800,
  autoplay: {
    delay: 3200,              // ② 每 3.2 秒自动翻页
    disableOnInteraction: false // ② 手动操作后不停止
  },
  pagination: {
    el: '#wyPag4',            // ③ 圆点挂载元素
    clickable: true           // ③ 圆点可点击
  }
});
✅ 验证通过：拖动一轮松手后约 3.2 秒轮播继续自动翻页，cube 翻转正常，圆点可跳转。一句话结论：把"手动操作后不停止"翻译成参数语言 disableOnInteraction: false 写进提示词后，AI 一次生成到位。

答辩抽问准备

可能的提问我的回答
两轮提示词差在哪？第 2 轮多了"手动操作后自动播放不停止"这一约束，对应参数 disableOnInteraction: false
为什么不能只写"自动播放"？Swiper 默认用户一交互就停自动播放（默认 true），不写清楚 AI 不会主动加
无缝循环是哪个参数？loop: true，Swiper 会克隆首尾 slide 实现无缝
圆点可点击的关键？pagination 里既要 el 指定元素，又要 clickable: true，漏一个都点不了
心得体会？把"人话需求"逐条翻译成组件的参数语言，约束越明确，AI 返工越少

2creative 电影墙仿写

参考官方示例 swiper/demo/257-effect-creative.html，为演示四新增第 7 个按钮「creative 电影墙」。核心配置：

creativeEffect: {
  limitProgress: 2,
  prev: {  // 上一张：缩小左移并带角度
    shadow: true,
    translate: ['-120%', 0, -300],
    rotate: [0, 0, -10],
    scale: 0.7,
    opacity: 0.6
  },
  next: {  // 下一张：放大右移进场
    shadow: true,
    translate: ['120%', 0, 0],
    rotate: [0, 0, 10],
    scale: 1.15
  }
}

用自己的话解释 prev / next 的 transform 各控制什么

prev 控制的是"当前这张离开时变成什么样"：翻页瞬间，正在展示的这张 slide 会朝着 prev 描述的状态过渡——translate: ['-120%', 0, -300] 让它向左移出屏幕并向后退（z 轴 -300 产生纵深），rotate: [0, 0, -10] 让它带一个逆时针 10° 的倾斜角，scale: 0.7 让它缩小到七成，opacity: 0.6 让它变淡。合起来就是"上一张缩小、左移、带角度地退场"。

next 控制的是"下一张进场前站在哪"：还没轮到的 slide 停在 next 描述的位置待命——translate: ['120%', 0, 0] 让它站在屏幕右侧之外，scale: 1.15 让它以放大 15% 的姿态准备，rotate: [0, 0, 10] 带顺时针 10 度角。翻页时它从这个状态渐变回正常大小和位置，看起来就是"下一张放大着从右侧进场"。

一句话总结：prev 决定旧照片的退场姿势，next 决定新照片的入场起点，中间的过渡动画由 Swiper 按 speed 自动补间。

② 课堂没讲过的 Swiper 能力：keyboard 键盘控制

加载在演示四 #wySw4 上（课堂讲了 loop / autoplay / pagination / navigation / effect，没讲键盘模块）：

keyboard: {
  enabled: true,        // 开启键盘控制
  onlyInViewport: true  // 只在轮播进入可视区域时响应，避免抢全局按键
}
✅ 验证：点击演示四轮播区域后，按键盘 ← / → 方向键即可前后翻页，与自动播放、圆点、效果切换互不冲突。
